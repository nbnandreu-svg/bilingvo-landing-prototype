# Перенос Билингво в Tilda

Готовая страница: https://nbnandreu-svg.github.io/bilingvo-landing-prototype/

## Вставка всей страницы

1. Добавьте на пустую страницу Tilda блок **T123 — HTML-код** из категории «Другое».
2. Откройте файл `T123-full.html` в текстовом редакторе и скопируйте все содержимое в блок.
3. Уберите стандартные верхний и нижний отступы блока, если они заданы в настройках.
4. Опубликуйте страницу. Tilda запускает пользовательский HTML/CSS/JavaScript на опубликованной странице. В редакторе поведение может отличаться.

Официальная инструкция: [HTML-код в Tilda](https://help.tilda.cc/html).

Вставка включает разметку, стили и JavaScript. Видео, изображения и шрифты загружаются из репозитория Билингво на GitHub Pages по постоянным адресам. Внутри нет временных ссылок Figma.

Стили ограничены контейнером `#bilingvo-site`, а идентификаторы имеют собственный префикс. Это проверено на тестовой странице с посторонними блоками. Вставляйте полную страницу один раз: второй экземпляр с тем же идентификатором добавлять не нужно.

## Что работает

- Объемный географический глобус: вращение на 360 градусов, скрытие обратной стороны, выбор городов и плавный поворот к стране выбранного языка.
- Демонстрационный телефон с появляющимся текстом и озвучкой.
- Английский, французский, арабский и китайский в телефоне и блоке прослушивания. На каждом языке воспроизводятся три готовых аудиофрагмента.
- Автоматическая смена фотографий, стрелки, пауза, свайп. При наведении курсора и работе с клавиатуры автопрокрутка приостанавливается.
- Видеоотзыв внутри карточки и ролик о мероприятии в отдельном окне.
- Переключение шагов подключения, раскрытие вопросов, окна заявки и запроса записи.
- На мобильных экранах блоки перестраиваются. При системной настройке уменьшения движения автопрокрутка и декоративная анимация отключаются.

Озвучка запускается только по нажатию. Одновременно воспроизводится один источник звука.

## Формы и подключение к продукту

В текущем прототипе заявки **не отправляются**. Окно успешной отправки показывается только после успешного ответа подключенного обработчика. При отсутствии обработчика форма прямо сообщает, что отправка еще не настроена.

При переносе подключите штатную форму Tilda к нужному получателю: почте, CRM или другому сервису. [Инструкция по формам](https://help.tilda.cc/forms).

Если используете штатные popup-формы Tilda, создайте их в проекте и задайте их ссылки перед основным кодом:

```html
<script>
window.BilingvoConfig = {
  tildaProjectPopup: '#popup:bilingvo-project-form',
  tildaSamplePopup: '#popup:bilingvo-sample-form'
};
</script>
```

Это переключает верхние и нижние кнопки вызова окна на штатные popup-формы. Встроенные формы внутри секций отдельно заменяются формами Tilda или подключаются к обработчику через `formEndpoint`.

Для собственного обработчика заявок предусмотрен параметр `formEndpoint`. Он должен принимать POST JSON, возвращать код 2xx только после принятия заявки и разрешать запросы с домена опубликованной страницы. Не размещайте секретные ключи в коде страницы.

```html
<script>
window.BilingvoConfig = {
  formEndpoint: 'https://YOUR-DOMAIN.example/api/bilingvo-leads',
  privacyUrl: 'https://YOUR-DOMAIN.example/privacy',
  companyUrl: 'https://YOUR-DOMAIN.example/company',
  roomUrl: 'https://YOUR-PRODUCT.example/join',
  roomCodeParameter: 'room'
};
</script>
```

Замените примерные адреса своими. Пока адрес входа `roomUrl` не задан, поле кода комнаты не ведет в реальный продукт. Юридические документы также подключаются отдельными адресами.

Кнопка запроса 15-минутной записи и соответствующая форма перенесены из Figma. Самой записи такой длительности в предоставленных файлах нет: автоматическую выдачу или отправку этой записи необходимо настроить после ее предоставления. Два включенных видео имеют продолжительность около 56 и 46 секунд.

## Редактирование

`T123-full.html` представляет собой HTML-вставку. Ее текст и стили редактируются в коде, а не как отдельные элементы Zero Block. Если страницу будете собирать в Zero Block вручную, исходные `index.html`, `styles.css`, `motion.css` и `app.js` остаются в корне проекта.

После изменений пересоберите вставку:

```powershell
python scripts/build_tilda.py
```

Для сборки нужны `beautifulsoup4` и `tinycss2`. Для работы готовой страницы Python и сборщик не нужны.

## Состав исходников

- `index.html` — обновленная структура и тексты.
- `styles.css` — базовые стили лендинга.
- `motion.css` — актуальный дизайн, адаптивность и оформление интерактивов.
- `app.js` — воспроизведение, переключение языков, галерея и модальные окна.
- `assets/audio/` — 12 аудиофрагментов из локальных материалов Билингво.
- `assets/video/jilal.mp4` — видеоотзыв из `IMG_9757.MOV`.
- `assets/video/event.mp4` — ролик с мероприятия из `IMG_9756.MOV`.
- `T123-full.html` — готовая полная вставка.
- `preview.html` — тестовая страница для проверки изоляции стилей, не предназначена для вставки.

## Компактная вставка

На странице Tilda используется `T123-compact.html`: разметка находится в T123, стили и скрипты загружаются из GitHub Pages. Это сохраняет редактируемую HTML-структуру без iframe.
